Text/icon	Function
```
U	Show only military/interesting aircraft
H	Home: recenter/reset map
T	Select all aircraft / show all tracks
L	Toggle aircraft labels
O	Cycle extended label details
K	Toggle labels on track lines
V	Limit aircraft list to those in view
M	Multi-select aircraft
P	Persistence: retain aircraft after signal loss
I	Isolate selected aircraft
R	Follow a random aircraft
F	Follow selected aircraft
Stacked layers	Choose base map and overlays
Left arrow	Open/show the aircraft sidebar
Corner brackets	Full-screen map
Gear	Display settings and units
+ / −	Zoom in/out
Aircraft symbols	Position and heading
Colored trails	Previous aircraft positions
Bottom color bar	Altitude-color scale
20 NM	Map distance scale
Orange–purple aircraft colors	Approximate altitude
Gray aircraft	On the ground
```

The letter buttons are also keyboard shortcuts.
